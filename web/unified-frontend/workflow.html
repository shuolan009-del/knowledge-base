工作流

两条流水线，一个控制台

导入与检索各由一条 LangGraph 流程驱动，按节点顺序依次执行。

导入流水线

把上传的文档解析、切分、识别主体并写入向量库。

  1. 检查文件类型
  2. PDF 转 Markdown / Markdown 图片处理
  3. 文档切分
  4. 主体名称识别
  5. 向量生成（BGE-M3）
  6. 写入向量库

检索流水线

先确认主体，再多路召回、融合重排，最后由大模型生成答案。

  1. 主体名称确认
  2. 向量检索 / HyDE 检索 / 联网检索（并行）
  3. RRF 融合
  4. 重排序
  5. 大模型生成答案

两条流程共用同一套节点契约：每个节点实现 process(state)， 由基类包装日志与进度上报，前端据此在「建库」页展示节点步骤条、在「对话检索」页展示阶段进度。
